## Objetivo

Desenvolver um sistema CRUD para controlar o estoque de uma loja de roupas utilizando vetores.

## Funcionalidades

1. Cadastrar produto
2. Listar produtos
3. Atualizar produtos
4. Excluir produto
5. Registrar produto
6. Ver estoque baixo
7. Sair

## Operações CRUD

- Create: cadastro de um novo produto.
- Read: listagem dos produtos cadastrados.
- Update: atualização dos dados de um produto.
- Delete: exclusão de um produto.

## Funcionalidades adicionais

Além do CRUD, o sistema permite registrar vendas, diminuindo a quantidade disponível no estoque, e consultar quais peças possuem menos de 5 unidades.

## Estruturas utilizadas

- Variáveis
- Vetores
- `while`
- `switch/case`
- `if/else`
- Booleanos
- Operações com vetores
